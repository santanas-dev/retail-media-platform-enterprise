# `docs/product/generated/` — сгенерированные проекции roadmap

**Ни один файл в этом каталоге не редактируется руками и не является каноном.**

Файлы производятся `scripts/ci/roadmap-generate.py` (задача `RM-GOV-003`) из SSOT-входов
и перезаписываются целиком при каждом прогоне.

| Файл | Что это |
|---|---|
| `roadmap.generated.md` | Markdown-проекция: очередь по этапам, гейты, решения владельца, матрица функций |
| `roadmap.generated.xlsx` | Книга из двух листов: `Технический Roadmap` (42 задачи), `Бизнес-функции Roadmap` (58 функций) |
| `roadmap-metrics.generated.json` | Машиночитаемые метрики — единственный источник чисел для отчётов |

## Входы (SSOT — правки вносятся только сюда)

| Вход | Чем владеет |
|---|---|
| `docs/product/roadmap.yaml` | последовательность работ, зависимости, приёмка, гейты, решения владельца |
| `docs/product/feature-registry.yaml` | функциональный статус `reachable`/`blocked` |
| `tests/ui-smoke/ci-subset.txt` + `tests/ui-smoke/*.py` | что реально закреплено в CI |

## Команды

```
python3 scripts/ci/roadmap-generate.py                     # перегенерировать
python3 scripts/ci/roadmap-generate.py --check-clean-diff   # упасть при дрейфе, ничего не писать
python3 scripts/ci/roadmap-generate.py --self-test          # tamper-матрица
```

## Границы, которые генератор соблюдает

1. **Односторонность.** Генератор не пишет во входы и в канон. Прогон сверяет sha256 входов и
   защищённых файлов до и после; расхождение — ошибка `ONE-WAY`.
2. **Действующее представление.** Cutover `RM-GOV-005` выполнен: вытесненные
   `roadmap.md` и `roadmap-s020-2026-07-10.xlsx` архивированы в `docs/product/history/`.
3. **Никаких домыслов.** Уровень зрелости берётся только из блока `maturity` в `roadmap.yaml`.
   Пока блока нет, проекция пишет «не заявлено», а не «0»: это разные утверждения.
4. **Детерминизм.** Ни времени, ни локали, ни зависимости от порядка словарей. Книга XLSX
   пересобирается с фиксированными метками времени, поэтому два прогона дают одинаковые байты.
